# Cafés del Pacífico · Control de vencimientos

Prototipo estático con Vite, React y TypeScript. Incluye login de demostración, vistas por rol, registro local de lotes, consulta de vencimientos y actividad ilustrativa.

## Uso

Requiere Node.js 20.19+ o 22.12+ y npm.

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

## Alcance

No hay backend ni autenticación real. El acceso por rol, bloqueo, inventario y actividad solo simulan estados en el navegador. Los datos añadidos se pierden al recargar. No ingresar contraseñas reales ni usar esta interfaz para proteger datos de producción. Historias de usuario: [docs/HUS.md](docs/HUS.md).
